# MLX Breeze TTS 2

- Purpose: standalone MLX port of Breeze TTS 2 with feature parity, conversion,
  serving, and evidence-driven Apple Silicon evaluation.
- Package: `src/mlx_breeze_tts`; Python >=3.10; MLX >=0.31.1.
- Interfaces: Python `load`/`Model.generate`, `mlx-breeze-tts2` CLI, FastAPI.
- Default tested model: `LunaFox/Breeze-TTS-2-mlx-4bit` revision
  `27be05f01bd8aad9628022c2bac6ded0119eef8a`.
- Approved scope and acceptance criteria: `docs/design/2026-08-31-approved-spec.md`.
- Evidence ledger: `docs/PROVENANCE.md`; generated evidence belongs in `reports/`.
- Selection research: `docs/research/2026-08-31-hot-tts-selection.md`.
- Low-disk BF16 candidate: `link-bf16`; static-only audit: `inspect-checkpoint`.
- Full acceptance runner: `benchmark` emits 23-case JSON/Markdown/WAV/HTML evidence.
- Real-device orchestration: `scripts/run_real_device_pipeline.zsh` resumes without deleting artifacts.
- Parity capture: `setup_official_parity_env.zsh` → `run_parity_capture.zsh`.
- Objective evidence: `objective-template` → `evaluate-objective-metrics` → `apply-objective-metrics`.
- Release evidence: `reports/release-v2/{bf16,8bit,4bit}`; parity: `reports/parity/`.
- Finalize reviews: `scripts/finalize_release_evidence.zsh BF16_JSON 8BIT_JSON 4BIT_JSON`.
- Final evidence order: raw → objective metrics → parity → real HTTP → listening → quantization selection → rendered final report.
